# 项目介绍与个人优势（实测版）

## AI 智能导购商城（Spring Boot 3 + Vue 3 + DeepSeek Agent）

GitHub：<https://github.com/Achtsix/ai-mall>

项目介绍：基于 Spring Boot 3、Vue 3 和 OpenAI 兼容大模型接口开发的电商 AI 导购平台，集成 RAG 商品知识库、Function Calling 工具中心和 ReAct Agent 自主决策。系统包含用户端商品浏览、购物车、余额支付，管理员端商品、订单、知识库管理，以及 AI 商品问答和个性化导购推荐。项目使用独立测试库和固定数据集验证搜索、鉴权、RAG、工具调用、Agent 与前端核心流程。

主要工作：

1. 使用 Spring Boot 3、MyBatis 和 PageHelper 实现商城后端及 10 个用户端路由。商品接口支持关键词、分类、品牌、最低价、最高价 5 类查询条件，关键词覆盖名称、卖点、详情、参数、分类和品牌；40 条固定查询集上 nDCG@5 为 0.63。
2. 基于 Hutool JWT、拦截器和 ThreadLocal 实现登录与角色鉴权，补充 Token 过期校验；6 类访问场景全部通过，20 线程共 2000 次交错身份请求中未发现身份串号、越权放行或请求错误。
3. 实现最多 420 字、60 字重叠的语义切片，以及向量与词法融合检索。在本地 256 维降级向量模式的 40 条检索集上，混合检索 nDCG@5 达到 0.86，相比纯向量 0.79 提升 9.36%，Recall@5 达到 0.95。
4. 实现动态 Function Calling 工具中心，7 个启用工具均可生成合法 JSON Schema；价格、库存、订单和售后由后端真实查询，推荐落库前二次校验。本轮测试核对 26 项价格/库存事实，错误为 0。
5. 使用 ReAct 模式实现最多 8 步的导购决策循环，并以 Agent Run/Step 记录执行轨迹。10 个导购场景全部完成，9 个生成有效推荐且审计记录完整，延迟中位数 12.219 秒、P95 17.073 秒。
6. 使用 Vue 3 Composition API、Element Plus、Pinia 和 Axios 完成用户端与管理员端页面，Vite 代理支持按环境切换后端。Playwright 验证用户购物支付、管理员核心入口和移动端导航，3 条端到端流程全部通过。

## 个人优势

1. 具备 AI 应用全栈交付能力，独立完成 Spring Boot 3 后端、Vue 3 双端页面和 ReAct Agent，项目包含 27 张业务表、商品交易闭环及 AI 导购链路。
2. 具备 LLM 工程化实践经验，能够区分聊天模型、Embedding 和本地降级方案，并通过固定问题集量化 RAG 混合检索效果，避免使用无法复现的“准确率提升”数据。
3. 重视确定性事实与大模型生成的边界，通过 Function Calling、真实数据库查询和推荐快照二次校验控制价格、库存等事实错误，同时保留 Agent 全步骤审计。
4. 具备测试和问题定位能力，建立独立基准库、40 条搜索集、40 条 RAG 集、2000 次并发鉴权测试、28 个在线 AI 场景及 Playwright 核心流程，并保留 JSON 原始结果与失败案例。

## 使用边界

- 本轮离线检索使用 `LOCAL_FALLBACK:256`，不描述为 DeepSeek Embedding。
- `getUserProfile` 从用户订单、订单商品和收藏数据派生画像；没有历史行为时返回空画像。
- 0% 价格/库存事实错误仅对应本轮 26 个已核对断言。
- 搜索 40 条用例仍有 14 条零命中，后续应增加同义词与语义召回。
