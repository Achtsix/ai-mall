# AI Mall 项目总结

## 项目概况

**技术栈**:
- 后端: Spring Boot 3.3.5 + Java 17 + MyBatis + MySQL 8.0
- 前端: Vue 3 + Vite + Element Plus
- AI: DeepSeek/OpenAI API + RAG混合检索 + Agent编排

**核心功能**:
1. AI智能导购 - 自然语言理解与商品推荐
2. 电商核心流程 - 浏览、购物车、下单、支付
3. 管理后台 - 商品、用户、AI配置、知识库管理
4. 响应式设计 - 移动端和桌面端适配
